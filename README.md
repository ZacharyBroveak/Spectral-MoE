# Spectral-MoE

**Heterogeneous Per-Layer Expert Utilization in Dense-to-MoE Conversion**

Spectral-MoE learns heterogeneous per-layer expert utilization under a fixed per-token budget for dense-to-MoE conversion, with static and dynamic allocation.
